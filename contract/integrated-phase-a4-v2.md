# Integrated ticketing Phase A4 — public event and demo buyer contract v2

Date: 2026-10-21. Prospective under `brief/project.json` v98. This supersedes v1 and incorporates `frontend/integrated-phase-a4-review-v1.md`. Frontend final agreement and PM handoff precede code. A4 publishes owner-approved A2 drafts to Neon and provides a zero-charge buyer demonstration. Existing Blob listings and receipts remain independent. There is no real sale, reservation, admission ticket, payment, email or referral payout.

## Public and private boundaries

The brand owner alone can publish or cancel. Editor/viewer active members can read owner projections but cannot publish/cancel. An immutable public event snapshot has a stable UUID URL `/events/{id}`; its source draft becomes locked by `public_events.source_draft_id UNIQUE`. A2 PATCH checks this constraint inside its draft transaction and returns `PUBLISHED_LOCKED`. Post-publish editing is excluded pending owner policy. Cancellation preserves event detail, media references and existing receipts; it blocks new quotes and checkouts.

Migration 004 creates `public_events`, `public_occurrences`, `public_tiers`, `public_sections`, `public_seats`, `public_inventory_pools`, `public_media_refs`, `demo_quotes`, `demo_receipts`, and idempotency claims. Each public row carries `organizer_id` and `event_id` where relevant; foreign keys and unique indexes enforce brand/event membership. `public_events` stores source draft/version, status, publish/cancel timestamps, version, cancellation reason and immutable snapshot. No Supabase data is imported. Private media is referenced, never copied or exposed by Blob URL; A3 deletion must reject assets referenced by a public event, including a cancelled one.

All JSON responses are `{data:<shape>,error:null}` on success or `{data:null,error:{code,message,fields?:[{path,code,message}],currentVersion?:number,publicUrl?:string}}` on failure. Field paths use A2 JSON pointers such as `businessLocation.address`, `businessLocation.latitude`, `businessLocation.photoAssetId`, `eventLocation.photoAssetId`, `disclaimer`, `schedule.dates[0].startLocal`. Validation error `PHOTO_NEEDED` points at the relevant photo field. No private path, Clerk subject, provider token or buyer PII enters public DTOs.

## Publication model and routes

Publishing validates the current version; title/type/timezone; at least one future occurrence; ticket format; at least one named tier with USD integer-cent price; total capacity and allocation; business address, exact pin and ready same-brand photo; separate event address/pin/photo if `sameLocation=false`; reviewed disclaimer and explicit refund policy. Restrictions may be blank. Optional cover, if present, must be ready and same-brand. A3 upload must be enabled before valid new-photo publication; a missing photo returns 422, never a fabricated image. A2 bounds remain: 366 occurrences, 50 sections, 10,000 seats. Local date/time is `YYYY-MM-DDTHH:mm` plus IANA timezone. DST gaps/overlaps return 422 `SCHEDULE_TIME_INVALID`/`SCHEDULE_TIME_AMBIGUOUS` at the offending date path; no guessed offset.

`inventory.dateScope` is `per_occurrence|across_dates`; `tierScope` is `shared|allocated`. In allocated mode each positive tier allocation sums to positive `totalCapacity`; in shared mode tier allocations are null. Pools are created per occurrence or once event-wide according to `dateScope`, with total and optional per-tier rows according to `tierScope`. These are configured ceilings only; demo checkout never decrements them. Seat policies `none|optional|required` allow mixed general-admission and seated tiers. `none` selects zero seats; `required` selects one compatible seat per ticket; `optional` permits assigned and unassigned places in the same tier line. A tier with `optional|required` requires at least one compatible configured seat. `seatTierId=null` permits any seated tier; otherwise only the matching tier. Seat IDs are stable UUIDs generated from publish geometry; row/number pair is unique within section. Accessible flags are information for all guests, never an eligibility gate. A single quote cannot select more distinct seats than compatible geometry; seat count need not equal total capacity, especially for mixed admission or cross-date pools.

`POST /api/v1/organizers/{org}/events/{draftId}/publish` accepts same-origin JSON `{expectedVersion:integer,idempotencyKey:UUID}` ≤8 KiB. Transaction: lock source draft and membership, validate current snapshot and referenced media, claim `(subject,org,draft,key)` with canonical request hash, expand occurrences/tiers/seats/pools, insert public rows and media refs, commit. Success 201 `{data:{event:{id,status:"published",version:1,sourceDraftId,publishedAt},publicUrl:"/events/{id}",warnings:[]},error:null}`. Identical key/body replays this result before rechecking current draft status. Reused key with different body: 409 `IDEMPOTENCY_CONFLICT`. Different key for published draft: 409 `ALREADY_PUBLISHED`, with `publicUrl`; stale unpublished draft: 409 `STALE_VERSION`, with `currentVersion` and a safe refetch via A2 GET. Retry after uncertain network result uses the **same** key.

`POST /api/v1/organizers/{org}/published-events/{id}/cancel` accepts same-origin `{expectedVersion:integer,idempotencyKey:UUID,reason:string}` ≤8 KiB, reason 0–500 chars. Transaction locks owner membership and event, claims idempotency, changes status/version once. Success 200 `{data:{event:{id,status:"cancelled",version,cancelledAt,reason},publicUrl},error:null}`. Same key/body replays even after cancellation; different key on cancelled event returns 409 `ALREADY_CANCELLED` with current version/public URL. `GET /api/v1/organizers/{org}/published-events/{id}` returns the owner projection to active members. Nonmember/foreign IDs return 404; disabled membership 403; editor/viewer mutation 403. No cancellation email, refund or payout.

## Exact public projections

All public event IDs are UUIDs, currency is `USD`, monetary amounts are integer cents, and nullable fields are explicit. Catalog uses `GET /api/v1/events?cursor=&limit=` (limit 1–50, default 20), sorted by `(publishedAt DESC,id DESC)` with a cursor tied to that ordering. Success `{data:{events:PublicEventSummary[],nextCursor:string|null},error:null}`. Only published, noncancelled events appear. `PublicEventSummary` is:

```json
{"id":"uuid","title":"string","type":"string","organizer":{"id":"uuid","name":"string"},"location":{"name":"string","address":"string","latitude":0,"longitude":0},"nextOccurrence":{"id":"uuid","startLocal":"2026-10-30T19:00","startsAtUtc":"2026-10-30T23:00:00.000Z","timeZone":"America/New_York"},"startingPriceMinor":2500,"currency":"USD","coverImageUrl":"/api/v1/events/uuid/media/cover","detailUrl":"/events/uuid","demo":true}
```

`nextOccurrence` and `coverImageUrl` are nullable. `GET /api/v1/events/{id}` returns `{data:{event:PublicEventDetail},error:null}` for published or cancelled events, otherwise 404. Detail extends every summary field and has these **exact** additional fields:

```json
{"status":"published","description":"string","restrictions":"string","disclaimer":"string","refundPolicy":"string","ticketFormat":"digital","businessLocation":{"name":"string","address":"string","latitude":0,"longitude":0,"photoUrl":"/api/v1/events/uuid/media/business","mapUrl":"https://..."},"eventLocation":{"sameAsBusiness":true,"name":"string","address":"string","latitude":0,"longitude":0,"photoUrl":"/api/v1/events/uuid/media/business","mapUrl":"https://..."},"occurrences":[{"id":"uuid","startLocal":"2026-10-30T19:00","startsAtUtc":"2026-10-30T23:00:00.000Z","endsAtUtc":"2026-10-31T01:00:00.000Z","timeZone":"America/New_York","durationMinutes":120,"status":"scheduled"}],"tiers":[{"id":"uuid","name":"Adult","description":"string","priceMinor":2500,"currency":"USD","seatPolicy":"optional","configuredAllocation":null}],"inventory":{"dateScope":"per_occurrence","tierScope":"shared","totalCapacity":20,"configuredOnly":true},"sections":[{"id":"uuid","name":"Front","layout":{"kind":"grid","rows":10,"columns":10},"configuredSeatCount":100,"accessibleSeatCount":4,"compatibleTierIds":["uuid"]}],"referral":{"enabled":false,"percentage":null,"payoutConnected":false},"demo":true,"seatSelectionReserves":false,"paymentConnected":false}
```

`ticketFormat` is `digital|paper|both`; `status` is `published|cancelled`; occurrence status is `scheduled|past`; tier `seatPolicy` is `none|optional|required`; `configuredAllocation` is null for shared pools. If `sameAsBusiness=false`, event location has its own address/pin/photo/map URL. Map URL is a server-constructed public Google Maps link from coordinates; it is never a secret API token. Section `layout` coordinates are visual layout grid positions, **not geography**. Detail does not include all 10,000 seat rows. Occurrences sort by UTC start then ID; tiers and sections sort by configured position then ID. Location photos are required; optional cover URL is nullable. Section `compatibleTierIds` includes each seated tier permitted by its seat assignments; individual seat compatibility remains authoritative on the seat page and server quote validation.

`GET /api/v1/events/{id}/occurrences/{occurrenceId}/seats?sectionId={uuid}&cursor=&limit=` requires `sectionId`, validates that it belongs to the public event, and returns at most 200 rows (default 100). Response `{data:{sectionId:"uuid",seats:[PublicSeat],nextCursor:string|null},error:null}`. `PublicSeat` is `{id:"uuid",sectionId:"uuid",sectionName:"Front",row:"A",number:"12",label:"Front · A12",x:0,y:0,accessible:true,compatibleTierIds:["uuid"],configuredOnly:true}`. `x,y` are bounded section-layout coordinates. Seats sort `(row natural,number natural,id)`; cursor encodes event, occurrence, section and last sort key, and a mismatched cursor/filter returns 400 `INVALID_CURSOR`. Seat list is the same configured geometry for each occurrence, not availability. No seat status or hold is emitted. Accessible seats remain selectable by all guests.

Public media route `GET /api/v1/events/{id}/media/{slot}` allows only `business|event-location|cover`, resolves immutable public refs, streams an allowlisted MIME from private Blob through server, sends `nosniff`, inline disposition, same-origin resource policy and bounded cache headers. For same-location event, `event-location` resolves the business asset. Missing optional cover returns 404; missing referenced data returns 503 and operations alert. Image failure does not fail event JSON or the page; Frontend renders a labelled visual fallback. No direct Blob URL or arbitrary asset proxy.

## Quote, checkout and receipt

`POST /api/v1/events/{id}/demo-quotes` accepts same-origin JSON ≤16 KiB `{idempotencyKey:UUID,occurrenceId:UUID,items:[{tierId:UUID,quantity:integer,seatIds:UUID[]}]}`. At most 10 distinct tier rows and 20 total tickets. Seat IDs are unique across the request and compatible with tier/section; none/required/optional policies enforce 0/exactly quantity/at most quantity seats. Optional tier lines may mix assigned and unassigned places. Quote checks configured total/tier pool ceiling for the applicable date scope and future occurrence, **not** remaining availability. No buyer identity or payment data is accepted. Seat labels are captured as immutable objects `seats:[{id,label,sectionName,accessible}]` per item in selection order; `unassignedQuantity=quantity-seats.length` is explicit.

Success 201 `{data:{quote:{id,eventId,occurrenceId,eventVersion,items:[{tierId,name,quantity,unitPriceMinor,seats,unassignedQuantity}],ticketSubtotalMinor,platformFeeMinor,organizerShareMinor,amountChargedMinor:0,currency:"USD",expiresAt,demo:true,seatSelectionReserves:false},checkoutUrl:"/events/{id}/demo-checkout?quote={quoteId}"},error:null}`. Fee is 10% of ticket subtotal, rounded half-up to cents; organizer share is subtotal minus fee, before any inactive referral illustration. Quotes expire in 15 minutes and hold nothing. Quote IDs are random unguessable UUIDs. Same key/same canonical selection replays the original quote (including its original expiry); changed request with same key yields 409 `IDEMPOTENCY_CONFLICT`. If event cancelled, 409 `EVENT_CANCELLED`; version changed, 409 `EVENT_CHANGED`; past occurrence, 409 `OCCURRENCE_PASSED`; invalid seat/tier, 422 `INVALID_SELECTION` with field paths. These errors direct visitor back to event detail or seat selection.

`GET /api/v1/events/{id}/demo-quotes/{quoteId}` returns the identical no-PII quote projection for checkout refresh, plus `state:"ready"|"expired"|"event_cancelled"|"event_changed"|"occurrence_passed"`. It does not renew expiry. A random quote ID is a bearer capability for viewing this no-PII selection and performing the zero-charge checkout from another browser; it is **not** bound to the anonymous demo cookie. Apply rate limits to quote reads as well as writes. An unknown/mismatched ID returns 404. For non-ready states, return 200 with state so checkout can show a recovery action; POST checkout returns the specific 409 code. `Cache-Control:no-store` and `Referrer-Policy:no-referrer` protect the query-string capability.

`POST /api/v1/events/{id}/demo-checkouts` accepts same-origin `{quoteId:UUID,idempotencyKey:UUID}` ≤8 KiB. Idempotency lookup by key and canonical body happens **before** checking current event status, quote expiry or occurrence. Thus a retry after a lost successful response returns the committed receipt even after cancellation. For a new key, lock quote and event in one transaction; require ready quote, verify server-priced immutable selection and configured seat compatibility, write exactly one immutable receipt for the quote; never decrement stock or set seat status. Success 201 `{data:{receipt:{id,eventId,eventStatus:"published",occurrenceId,items:[{tierId,name,quantity,unitPriceMinor,seats:[{id,label,sectionName,accessible}],unassignedQuantity}],ticketSubtotalMinor,platformFeeMinor,organizerShareMinor,amountChargedMinor:0,currency:"USD",demo:true,admissionValid:false,createdAt},receiptUrl:"/demo/receipts/{id}"},error:null}`. A second key for an already used quote returns 409 `QUOTE_ALREADY_USED` with `receiptUrl`, so the visitor can recover. Other 409 codes are `QUOTE_EXPIRED`, `EVENT_CANCELLED`, `EVENT_CHANGED`, `OCCURRENCE_PASSED`; each offers return to event/selection, never a payment retry. No buyer details, payment row, issued ticket, QR/barcode, email or reservation.

`GET /api/v1/demo/receipts/{id}` returns `{data:{receipt:<same immutable receipt projection with current eventStatus>},error:null}`, no PII and `Cache-Control:no-store`. `/demo/receipts/{id}` is public/shareable via opaque UUID, not indexed or listed. It says “Demo confirmation — no payment or reservation” and “Not valid for admission.” If cancelled, show cancellation notice; no refund claim because nothing was charged. Receipt share retention is a pending owner decision.

## Cutover, security and gates

`NEXT_PUBLIC_NEON_DEMO_CATALOG_ENABLED` defaults **off**. Off: `/` and `/discover` keep only existing Blob cards/links. On: they render a **separate, labelled “New demo events”** Neon section with links to `/events/{id}`; existing Blob result counts, pagination and search remain untouched. `/discover` does not claim global Neon search; it presents the unfiltered section. If Neon returns 503, omit that section with a small unavailable message and keep legacy results usable. Enable only after catalog → detail → seats → quote → checkout → receipt browser/API/data checks, including cancellation and mobile/keyboard flow. No silent catalog merge, redirect or legacy deletion.

All mutating routes require same-origin, bounded JSON and UUID parsing. Private routes derive Clerk subject server-side and require active brand membership. Public reads use explicit bounded projections. Anonymous quote/checkout has a server-issued HttpOnly SameSite demo cookie solely for abuse control, with only its hash stored; quote capability remains independently usable across browsers. Per-cookie plus global-event quotas return 429 with `Retry-After`; absent cookie uses stricter event quota. Exact quota numbers await owner approval and block public activation. Idempotency records persist response identity and canonical hash within the same transaction as the mutation. No client price, selected seat label, referral reward or inventory claim is trusted.

Backend owns migration 004, publication/cancellation transactions, recurrence and DST handling, public projections/media, quote/receipt math and replay. Frontend owns review/publish/cancel screens, configured-seat UI, explicit zero-charge copy at selection/checkout/receipt, recovery states, image fallback and cutover section. Required tests: owner/editor/foreign-brand permissions; missing location/pin/photo/disclaimer; DST gap/overlap; mixed seated/GA and accessible choices; optional assigned+unassigned quantities; section-filtered pagination/cursor; duplicate/foreign seats; pool date/tier scope; concurrent publish/cancel and lost-response replay; quote expiry/cancel race; $0 charged/no stock decrement/no PII; missing media fallback; legacy isolation. No live-service claim without connected browser/API/data verification.

**PM decisions pending:** exact anonymous demo abuse limits, retention of no-PII shareable receipts, and A3 private-media quotas. Published-event edit policy remains unapproved and outside A4. Frontend final agreement is required before any A4 code. This contract changes no app code, database or external service.
