# Integrated Phase A4 backend implementation v1

Date: 2026-10-21. Implemented against `brief/project.json` v102 and the prospective, Frontend-agreed `contract/integrated-phase-a4-v2.md`. Brief v103 subsequently approved future published-listing edits; that is **post-A4** work and is absent here. No database migration was applied to a connected Neon project and no deployment was made.

## Implemented

- `migrations/004_integrated_phase_a4.sql` adds immutable public event snapshots, dated occurrences, tiers, sections, seats, configured inventory pools, public-to-private media references, demo quotes/receipts and rate counters. Publication locks its source draft through a database trigger. Public media references block A3 deletion, including after cancellation. Event/occurrence FKs prevent cross-event inventory and quotes.
- `lib/integrated-phase-a4-write.mjs` validates a complete A2 draft, expands bounded individual/weekly dates, rejects daylight-saving gaps and ambiguous wall times, prepares mixed general-admission and numbered seats, and performs owner-only publish/cancel transactions with idempotency. Same-key successful publish/cancel replays the committed response. Cancel retains existing demo receipts and media. The server will not invent a venue photo.
- `lib/integrated-phase-a4.mjs` and `lib/integrated-phase-a4-runtime.mjs` provide bounded public catalog/detail and section-filtered seat reads, owner event read, and a server-only private Blob media stream. `/listing/*` and `/receipt/*` legacy Blob paths are untouched. New public paths are `/api/v1/events/*` and `/api/v1/demo/receipts/*`.
- `lib/integrated-phase-a4-demo.mjs` calculates server-priced, exact-seat demo quotes, checked against **configured** pool ceilings only. Optional-seat tiers allow assigned and unassigned places in one quote. Accessible seats are selectable by anyone. Checkout stores a no-PII shareable receipt with `amountChargedMinor:0`, `admissionValid:false`, no seat or inventory mutation, no payment or message. Same-key receipt replay precedes event cancellation/expiry checks. Receipt GET remains accessible when checkout creation is disabled; owner-approved retention is until a future explicit event deletion feature, with no automatic purge in A4.
- Anonymous creation is **off by default**: `DEMO_CHECKOUT_ENABLED` must equal `true`, and `DATABASE_URL` must be present. The public Neon catalog is separately controlled by Frontend's default-off `NEXT_PUBLIC_NEON_DEMO_CATALOG_ENABLED`. This is an activation boundary, not proof that connected services work. Private A3 image uploads/deletes remain disabled under the revised free Blob limits, so ordinary organizers cannot yet satisfy required-photo publication in the connected app.

## Abuse controls

The server issues an HttpOnly SameSite cookie only for demo abuse control; rate counters store its SHA-256 hash, never an attendee name, email, IP address or payment data. Rotating or absent cookies cannot exceed per-event and global limits. Exact conservative defaults (overridable by bounded `DEMO_*` environment integers) are: 12 quotes per cookie/hour, 240 quotes per event/hour, 48 no-cookie quotes per event/hour, 1,000 quotes globally/hour; 4 checkouts per cookie/day, 80 per event/day, 16 no-cookie checkouts per event/day, 300 globally/day; 600 quote reads per event/hour. Exceeding a limit returns 429 `DEMO_RATE_LIMIT` and `Retry-After`. These are operational defaults chosen under brief v101, not a user promise or verified production capacity. They protect Neon writes, but distributed bot protection is future work.

## Verification and limits

`node --test tests/integrated-phase-a4.test.mjs` passed 6/6. Tests apply all four migrations to PGlite and exercise publish replay, draft lock, mixed seated/GA quote, accessible seat choice, configured price and 10% fee, $0 checkout, receipt after cancellation, limits, DST, projections and cursor scope. Focused A2+A4 tests passed 11/11. `pnpm run build` passed outside the Windows sandbox, where Next required junction creation permission. Full `pnpm run check` reached 294/296: the two legacy PGlite disk-restart tests (`local-store`, `ticket-format`) abort with the same WASM `Aborted()` error when rerun separately; A4 tests pass. This is not a clean full-suite result.

Connected Neon, Clerk and private Blob were **not** exercised. The current A4 runtime uses Neon pooled transactions for publish/cancel/quote/checkout; connected testing must verify pooling, migration, origin handling, media streaming, real browser refresh, cancellation race, mobile and keyboard paths before enabling the catalog or demo checkout. No paid checkout, admission ticket, reservation, digital confirmation email, affiliate payout or image/video upload is active. The owner-approved future edit-in-place policy needs a separate versioned contract and implementation that keeps old demo confirmations immutable.
